# 🗡️ codMaster
A script for Kingdom of Loathing. To set, save and equip gem configurations for The Eternity Codpiece.
&#10240;
## 🗡️ <ins>Installation / Uninstallation</ins><br/>
 &#10240; 🔹 To install, run the following on the gCLI:
 >     git checkout https://github.com/donCannoli-burns/codMaster.ash.git
 &#10240; 🔹 To uninstall, run the following on the gCLI:
 >     git delete https://github.com/donCannoli-burns/codMaster.ash.git
 &#10240; 🔹 To start the script, run the following on the gCLI:
 - To set gem configuration.
 >      codMaster init
 - To save your gem configuration.
 >      codMaster save <your config name>
- codMaster equip to equip your gem configuration.  
>       codMaster equip
- To see other options.    
>       codMaster help
